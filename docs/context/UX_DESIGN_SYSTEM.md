# Woody UX Design System

## Personality

Calm, intelligent, friendly, premium, and slightly playful.

## Visual rules

- Persistent desktop sidebar and glass top bar.
- Dense professional dashboard with subtle gradients and hairline borders.
- Geist for interface text; JetBrains Mono for technical metadata.
- Indigo for primary action, cyan for information, emerald for success, amber for warnings, rose for errors/destructive actions.

## Interaction rules

- Every visible primary action works or clearly explains why it is unavailable.
- Show loading, empty, error, and completed states.
- Reveal advanced settings progressively.
- Preserve keyboard and screen-reader access.
- Woody mascot assists the product; it does not replace the Woody logo.
