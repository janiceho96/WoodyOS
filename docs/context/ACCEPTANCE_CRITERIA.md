# Acceptance Criteria

A feature is complete only when:

- Backend capability exists and the frontend calls it.
- Loading, empty, error, permission, and completed states are handled.
- Secrets remain protected.
- Relevant unit tests and database integration tests pass.
- Frontend build passes.
- Docker configuration/build is checked when applicable.
- Visual behavior is checked for user-facing changes.
- Documentation and `CURRENT_STATE.md` are updated.
- Any remaining limitation is stated plainly.
