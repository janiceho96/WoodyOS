# Woody Context Index

Read `CODEX_WORKING_CONTEXT.md` first. It is the shortest orientation file. Then read `PROJECT_BRIEF.md`, `CURRENT_STATE.md`, and `ARCHITECTURE_DECISIONS.md` only when their added detail is relevant.

- Active Woody UX redesign: read `UX_REDESIGN_EXECUTION.md`; it is the compact execution source of truth and replaces rereading the original chat goal.
- Workflow work: also read `WORKFLOW_PRODUCT_SPEC.md` and `SECURITY_AND_TRUST.md`.
- Workflow foundation proposal: read `WORKFLOW_FOUNDATION_DESIGN.md` before changing workflow runtime, schemas, routes, or canvas storage.
- Workflow completion audit: read `WORKFLOW_ACCEPTANCE_MATRIX.md` before declaring any workflow phase complete.
- Frontend work: also read `UX_DESIGN_SYSTEM.md`.
- Product research: also read `PRODUCT_BENCHMARKS.md` and `DO_NOT_COPY.md`.
- Before declaring completion: read `ACCEPTANCE_CRITERIA.md`.

Keep these files concise. Record verified facts and approved decisions, not full source code or chat transcripts.
