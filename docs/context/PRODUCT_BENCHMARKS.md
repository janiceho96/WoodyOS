# Product Benchmarks

Use official documentation and direct product observation. Mark facts, inferences, and Woody decisions separately.

## n8n

### Learn

- Node registry, visual graph editor, resource/operation selection, data mapping, execution history, and credential separation.

### Woody adaptation

Use MCP/API adapters for integrations, richer agent/file outputs, cost visibility, and policy-controlled approvals.

### Do not copy

- Its visual identity, code, branding, or huge native connector maintenance burden.
- Arbitrary code execution or unrestricted expressions.

## LangGraph

### Learn

- Explicit graph state, checkpointing, controlled loops, interruption, resume, and subgraphs.

### Woody adaptation

Use durable state and resumable agent nodes without exposing unnecessary implementation complexity.

## Linear

### Learn

- Fast keyboard-friendly workflows, dense calm UI, and clear status language.

## Notion and Zapier

### Learn

- Progressive disclosure, beginner-friendly setup, and human-readable app/action language.

## ChatGPT / OpenAI products

### Learn

- Natural-language task entry, transparent tool status, file input/output, and confirmation before consequential actions.
