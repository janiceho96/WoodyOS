# Patterns Woody Must Not Copy

- Reference product code, UI, trademarks, or branding.
- Feature volume without a Woody user need.
- Unrestricted code or shell execution.
- Credentials embedded in workflow JSON.
- Fake search, AI, tool, or browser functionality.
- Automatic retries for non-idempotent external writes.
- Arbitrary JavaScript expressions.
- Generic “MCP Tool” labels when the exact app is known.
- Workflow formats coupled to one frontend canvas library.
- Agent autonomy without cost, iteration, permission, and audit limits.
